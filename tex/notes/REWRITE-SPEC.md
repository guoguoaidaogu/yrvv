# 重写规格（供各节撰写者遵守）

## 总目标
把 `md/N.md`（原始讲义，中文知乎体）改写为**数学教材风格**的 `tex/chapters/chNN.tex`。
教材风格 = 定义/定理/命题/例/注 结构清晰、叙述客观简洁、不带个人情绪与写作缘由、
不使用第一人称叙述研究经过。**不要**保留"我觉得""很有趣""读者可能会问""待研究""我还没学会"之类的话。

## 必须遵守
1. **删去原作者不必要的思考过程**：写作动机、心情、与读者的闲谈、对学科体系的感慨、
   对自己水平的评论、日期、后记、知乎链接与 @用户名、对别的书/别人的评价。
   只保留数学内容本身（包括必要的"为什么这样定义"的简短说明）。
2. **舍去所有图片**：原稿中 `![](assets/xxx.jpg)` 一律删除。若该图承载了数学信息，
   必须用文字补足（例如"设 $l$ 与 $g$ 交于 $p,q$，过 $p,q$ 的切线交于 $D$"这样把作图说清），
   或者在需要时用 TikZ 重新画出（仅在确实必要时，保持简单）。
   不要留任何 `\includegraphics` 或对图的引用（"如图所示"要改写成不依赖图的表述）。
3. **适当处勘误**：原稿有明显的数学错误、typo、指标上下写错、系数错、结论错时改正，
   并在该处附近用 `\begin{remark}...\end{remark}` 简短说明更正了什么（只写数学内容）。
   不要为了显示而改动没错的地方。
4. **输出 XeLaTeX**：中文用 `ctexbook` 已提供支持，直接用中文即可。
   行内公式 `$...$`，行间公式 `\[ ... \]` 或 `equation`/`align` 环境。
   使用 preamble 已定义的定理环境：`definition, theorem, proposition, lemma, corollary, example, remark, exercise`。
   不要在章文件里写 `\documentclass`、`\begin{document}`、`\usepackage`、`\tableofcontents`。
   文件以 `\chapter{...}` 开头（章号由 main.tex 的 `\part` 结构统一编号，不要手工写"第X节"编号）。
5. **章节结构**：用 `\section{...}` 与 `\subsection{...}` 组织，层次要合理。
   原稿里用加粗整段给出的"定义/命题"要转成对应的定理环境。

## 记号约定（必须严格遵守）
- 上指标 = 矢量（点矢），下指标 = 对偶矢量（线矢）。爱因斯坦求和约定。
- 矢量 $a,b,c,p,q,s$；对偶矢量 $k,l,m,n,u,v$；张量 $f,g,h$。
- 缩并 $a\cdot l=a^il_i$；点乘 $a\cdot b=g_{ij}a^ib^j$。
- 叉乘 $(A\times B)_i=\epsilon_{ijk}A^jB^k$；混合积 $[ABC]=\epsilon_{ijk}A^iB^jC^k$，$\epsilon_{123}=1$。
- 度规 $g_{ij}$，逆 $(g^{-1})^{ij}$；只有一条圆锥曲线并取作度规时写 $g^{ij}$。
  **涉及多条圆锥曲线时必须区分 $g^{ij}$（用 $g$ 升指标）与 $(g^{-1})^{ij}$（$g$ 的逆）。**
- 对称积 $(ab)^{ij}=a^ib^j+a^jb^i$，$(mn)_{ij}=m_in_j+m_jn_i$。
- 二次点乘 $f:h=f^{ij}h_{ij}$；二次叉乘
  $(f\times h)_{kl}=\epsilon_{imk}\epsilon_{jnl}f^{ij}h^{mn}$，
  $(f\times h)^{kl}=\epsilon^{imk}\epsilon^{jnl}f_{ij}h_{mn}$。
- 不写指标的写法：并列=不缩并，`\cdot`=缩并一个指标，`:`=缩并两个指标。
  例如 $gf$ 分量 $g_{ij}f^{kl}$，$g\cdot f$ 分量 $g_{ij}f^{jk}$，$f:g=f^{ij}g_{ij}$。
- 无穷远线矢 $\linf$；垂直张量 $\theta^{ij}$；$\theta$ 退化，号差 $(1,1,0)$。
- 二维空间反对称张量 $e_{ij}$，$e_{12}=1$，$e_{ij}e^{ij}=2$，$e_{ij}e^{ik}=\delta^k_j$，
  二维叉乘 $[ab]=a^ie_{ij}b^j$。
- 标准形式下的圆锥曲线 $g_{ij}=\diag\{1/a^2,1/b^2,-1\}$，$g^{ij}=\diag\{a^2,b^2,-1\}$。
  **不要沿用原稿里把 $g^{ij}$ 写成 $a^2,b^2,-1$ 同时又当 $g_{ij}$ 用的混乱写法。**

## 数学内容必须保持
改写的是**表达方式**，不是内容。原稿的全部数学结论、例题、推导链条都要保留（图的信息损失除外，
但要补足文字）。允许重新组织顺序、合并重复、补充严谨性，但不允许删掉知识点。
